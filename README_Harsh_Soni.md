# 📊 Blinkit Sales & Operations Analysis (MySQL)

## 📌 Overview
This project focuses on analyzing Blinkit’s sales and operational data using **MySQL**. The objective is to extract meaningful business insights related to sales performance, product demand, customer behavior, and operational efficiency through structured SQL queries.

---

## 🛠️ Tools & Technologies
- **Database:** MySQL  
- **Language:** SQL  
- **Tool:** MySQL Workbench  

---

## 🎯 Project Objectives
- Analyze overall sales and revenue performance  
- Identify top-selling and low-performing products  
- Perform category-wise sales analysis  
- Understand order and revenue trends  
- Generate data-driven business insights  

---

## 📂 Dataset Description
The dataset consists of structured sales and operations data, including:
- Order details  
- Product and category information  
- Quantity and pricing data  
- Sales and revenue metrics  

*(Dataset is assumed to be pre-loaded into MySQL tables.)*

---

## 🔍 Analysis Performed
- Total orders and total revenue calculation  
- Average order value analysis  
- Product-wise and category-wise sales breakdown  
- City-wise sales performance  
- Time-based sales trend analysis  

---

## 🧠 SQL Concepts Used
- SELECT, WHERE  
- GROUP BY, ORDER BY  
- Aggregate Functions (SUM, COUNT, AVG)  
- JOINS  
- Subqueries  

---

## ▶️ How to Run the Project
1. Create a database in MySQL  
2. Import the dataset into tables  
3. Open the SQL script file  
4. Execute queries in MySQL Workbench  

---

## 📈 Key Insights
- Identification of high-revenue categories  
- Recognition of top-performing products  
- Understanding sales trends and demand patterns  
- Actionable insights for business decision-making
